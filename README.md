# 小松鼠 · SquirrelFin

安卓优先的本地财富记录工具，采用暖灰、鼠尾草绿和简约卡片界面。当前源码版 0.1.25，无登录、服务器或广告；账本完全本地，更新检测与下载使用网络权限。

## 安装与试用

当前开发版可从 [GitHub Release v0.1.25](https://github.com/tyrantqiao/SquirrelFin/releases/tag/v0.1.25) 下载；APK 为 `SquirrelFin-0.1.25.apk`，附 SHA-256 校验文件。支持 Android 8.0 及以上，开发签名仅供试用，沿用原签名。安卓真机运行、断点续传和覆盖安装尚未验证。

电脑预览（Node.js 18+，无第三方依赖）：

```powershell
npm start
```

浏览器打开 http://127.0.0.1:4173 。预览与 APK 共用界面和计算模块，但各自独立保存数据。默认空账本，可选择体验明确标注的示例数据。

0.1.25 优化收支走势与参考时薪默认填写；此前新增「真实时薪」与工资、工作成本记账联动，单页设置并实时换算消费投入时间。

## 已实现

- 总览统一展示净资产、财富分布与今日收支，按组排版；统计口径和提醒按需展开，资产列表从资产页查看。
- 现金、投资、贵重物品、负债登记，存放位置与手工风险标签。
- 收入、支出、转账、投资追加与取出；整数分存储金额。备注支持检索本地历史内容并点选复用，候选去重、最近使用优先。
- 支出用途与性质分别记录：餐饮、居住、交通等用途，以及固定、日常可变、偶发性质；月度汇总不计内部转账和历史关联资金转出。
- 常用支出模板保留账户、金额、分类与每月/每年标记；手工确认后才生成流水，不自动记账、扣款或提醒。普通流水可编辑，旧流水保留未分类状态。
- 常用表单固定保存区，可选资料折叠；资产字段按类型展示；余额总结主动核对期间资金进出。
- 可选真实时薪：单页设置真实时薪，每日时长快捷点选，工资和个人承担的工作成本可从明确标记的流水动态汇总；支出即时换算投入时间，流水按交易日期匹配生效档案。支持历史档案调整、关闭换算、金额防窥及本地备份；不改变账务金额。
- 轻便记账：大号金额、自带数字键盘、用途图标点选、日常/固定/偶发标签、折叠账户与日期；保存后可再记一笔。
- 文字账单导入：粘贴或选择 UTF-8 TXT/Markdown 文件，支持日期、收支表情标记、原分类、备注、金额；先预览并核对账户，保留原分类，提示疑似重复和错误行，确认后整批追加。可切换月份查看历史收支。
- 资产估值更新、历史记录、收益金额、无现金流持有期收益率及 XIRR 年化。
- 定期更新资产余额，核对期间追加、取出与分红后计算收益。
- 长期投入在记账中登记；内部资金移动使用转账，避免财富重复增长。
- 实物成本、净残值及出售到账记录；出售后残值归零。
- 金额隐藏、完整 JSON 导出与恢复、数据验证与清空前确认。

## 数据与计算约定

初始金额是登记当天后续流水发生之前的余额；后续估值为该日日末余额，已经包含当日交易。估值后的日期流水继续调整当前余额。不能从稀疏快照还原日内交易顺序，因此收益仅计算至最后一次估值日期。

投资收益 = 期末估值 − 期初估值 − 区间净投入。没有现金流时显示持有期收益率；有追加或取出时使用 XIRR。所有后续估值区间现金流须由用户确认完整，才显示收益率。新增或删除历史交易会撤销后续估值的核验状态。年化结果不是未来收益承诺；无解或发现多解时不显示。

资产仅作本地记录，不执行外部投资。余额总结扣除已登记净投入；无资金进出时显示持有期收益率，有不规则现金流时使用历史 XIRR。未核验完整时不显示确定收益率。较上一估值扣除净投入后的偏差达到 20% 时加强资金进出提醒（仅作提醒阈值）。旧备份计划与关联记录保留兼容，但不再提供计划操作。

贵重物品残值为用户估计的预计变现净额，不是平台报价。出售后的归零记录和到账流水保留用于对账，首版不支持撤销出售。

安卓数据通过原子文件写入应用私有目录，浏览器预览通过 localStorage 保存。卸载或清除数据会丢失记录。请定期导出备份；备份为明文，未实现应用锁或额外数据库加密。应用仅为更新检测和安装包下载申请 INTERNET 权限，账本不上传；导出或导入文件的位置由系统文件选择器和用户决定。

## 安卓构建

可用 Android Studio 打开项目，安装 SDK 35，使用 JDK 17 与 Gradle 8.9 构建 `app`。项目没有 Gradle Wrapper，需要本机 Gradle 或 IDE 提供 Gradle。

本次 APK 使用 Google 官方 SDK 平台与 build-tools 独立构建，绕过 Gradle 的运行环境依赖：

```powershell
node tools/fetch-android.cjs
Expand-Archive -LiteralPath .build-tools/platform-35_r02.zip -DestinationPath .build-tools/platform -Force
Expand-Archive -LiteralPath .build-tools/build-tools_r35_windows.zip -DestinationPath .build-tools/tools -Force
.\tools\build-apk.ps1 -Jdk '你的 JDK 路径'
```

SDK 工具、开发签名与构建产物在 Git 忽略目录中。请保存 `.build-tools/debug.keystore`，丢失签名后无法覆盖安装已有开发版。构建脚本验证 APK v2/v3 签名，输出应用标识与 SDK 要求。

主要源代码：`app/src/main/assets/`（界面与计算）、`app/src/main/java/com/squirrelfin/app/MainActivity.java`（安卓离线存储与文件备份）。

## 0.1.3 应用更新

设置 → 应用更新，直接通过本项目 GitHub Release 网页检测最新正式版本，按数字版本判断，不再请求 GitHub API。读取官方 Release 安装包附件与同名 .apk.sha256 校验文件；支持暂停、网络失败后继续和应用重启后续传，服务器不支持 Range 时安全重新下载。安装前核验大小、SHA-256、包名、版本与签名。系统需要允许此来源安装，返回后再次点击安装。下载仅在应用进程存活时运行，退出后保留进度，不自动安装。浏览器预览提供 Release 链接，安卓应用提供下载与安装。

本地构建产物为 `dist/SquirrelFin-0.1.25.apk`，改动与验证说明见 [v0.1.25](docs/releases/v0.1.25.md)。v0.1.25 发布附件包含 APK 与同名 SHA-256 校验文件。发布需同时上传 APK 和 SHA-256 文件并沿用原签名；网页检测要求对应版本的唯一 APK 附件与同名 .apk.sha256 文件。

0.1.6 支持无需账户直接记账，取消抽屉与折叠交互；为非调试 Release 构建，明确关闭 debuggable/testOnly，沿用开发签名以保留覆盖安装兼容性，仍为试用性质。
