## 0.1.3 更新页验证（2026-10-11）

- 新增设置中的应用更新页，以 `tyrantqiao/SquirrelFin` GitHub 最新正式 Release 为依据，比较数字版本，忽略预发布；要求匹配 APK 资产及 GitHub SHA-256 digest。
