# 页面交互走查（2026-10-10）

核心原则：操作简洁、简单，常用任务一屏完成。

## 范围与证据

检查当前本地浏览器预览的现有示例账本，实际打开首页、记账、资产登记、投资详情、定投列表和定投核验弹窗；结合 app.js 与 style.css 检查其他路径。未保存或删除账务数据，未修改应用实现。截图视口约 530–545 × 650–668，属于窄屏浏览器布局；不是安卓真机验证，尚未验证手机软键盘、系统返回及 360/390 宽度。

| P0 | 记账默认收入；收入和支出也展示无关的转入账户 | 支出/收入/转账直接切换；仅转账展示转入账户，投资操作按账户类型呈现；金额优先 |
| P0 | 资产登记同时展示现金风险标签、实物成本和三类金额名称 | 类型决定字段与文案；默认仅名称、类型、金额，日期默认今天可改；地点、风险等放更多资料，实物才显示成本 |

| P2 | 列表每行直接展示删除，缺少编辑流水入口 | 点击行查看/更正，删除放详情；保持关联流水与收益核验的一致处理 |
| P2 | 多处使用多义文案和细小灰字，如关联账户/转出账户、核验、购入成本等 | 使用当前情境下的单一名称；主操作用确认成交、保存资产、保存记账等具体动词；必要规则就近简述 |

## 建议的一屏默认字段

- 记账：支出/收入/转账、金额、账户；转账增加转入账户；日期与备注作为紧凑次要区。
- 登记资产：类型、名称、初始金额；默认今天，更多资料按需展开。
- 更新余额：金额、估值日期；投资现金流核验必须显式保留，不能默认勾选。
- 新建定投：投入资产、每期金额、周期、首次日期；计划名称可自动建议且可修改，结束日期可选展开。
- 确认定投：计划期次摘要、实际状态、资金来源、实际金额、成交日期；失败/跳过只展示相关字段。

## 后续验收

以 360 × 800、390 × 844 手机尺寸检查默认任务，主按钮无需滚动寻找；在安卓真机上检查软键盘与系统返回。不可用缩小字号或触控区域达成一屏。历史列表允许滚动，一屏原则针对完成一次常用操作。保留本地保存、明文备份提示、替换确认、收益核验与财务守恒规则。
