# 轻便记账与文字导入（0.1.2）

## 日常记录

进入「记一笔」，点数字输入金额、点用途图标，再保存。默认今天与最近使用的现金账户；账户和日期以小标签呈现，点开修改。性质使用日常、固定、偶发标签。备注、常用模板和其余用途按需展开。编辑普通流水、转账和投资追加/取出仍可使用原有路径。

## 导入步骤

「记账 → 导入」中粘贴文字，或选择 UTF-8 TXT/Markdown 文件，再点「预览账单」。例如以下为人工示例，不是真实财务数据：

```text
2026-09-12 收入✔️ 劳动💪🏻 测试奖金 50
- 2026-09-12 支出❌ 日常 测试早餐 12
```

每行按「日期 收入/支出 原分类 备注 金额」解析，支持可选列表符号、表情、多余空格、备注内空格与末尾「元」。金额必须为正数且最多两位小数。每次最多 1000 行、15 万字；文件最大 600 KB。当前不支持 CSV、Excel、图片识别或负数退款。

预览默认本地仅记收支，不显示账户绑定，不改变资产余额。展开「调整分类」可修改单笔支出用途和性质；「批量调整分类」按原分类及可选备注关键词修改已选支出。可筛选其他分类或疑似重复，筛选不会取消隐藏记录的选择。点击确认后，追加已勾选记录，不替换原账本。分类建议如下：

- 玩 → 娱乐；礼物 → 人情／偶发。
- 日常中的房租 → 居住／固定；骑自行车 → 交通；早餐 → 餐饮。
- 未识别的支出标签 → 其他；原分类单独保留，可在流水详情追溯。
- 收入中的「投资」保留为来源标签，收支类型仍为收入，不会变成投资追加，也不会据此计算投资收益。公积金等仅保留收支记录，不自动归入可支配现金。

## 校验与数据约定

- 不接受无效日期或未来日期。格式错误标出原始行号，有错误时整批保存被阻止，不静默丢弃错误行。
- 此入口不关联资产，因此不受资产初始盘点日期限制。
- 按账户、日期、收支类型、金额、备注识别账本内及批内重复候选，默认不勾选。真实的同日同额同备注记录可手工勾选保留。
- 一次校验全部勾选记录，复制状态后整批提交；验证或存储失败不改变当前账本，不保留半份导入。
- 导入保留整数分金额，撤销受影响的后续现金流核验。同日流水包含在日末估值内；历史导入不会再次加到已有日末余额上。
- 导入完显示本批最近记录所属月份；月份控件可查看其他月份的收支与分类汇总。导入不会自动创建定投或物品出售关联记录。
- 所有解析均在本地，无联网服务。原分类为备份 version 1 的可选字段，旧备份保持可恢复。浏览器与安卓文件读取入口独立于完整 JSON 备份恢复。
