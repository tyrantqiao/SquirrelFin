# v0.1.1 开发版（本地构建，尚未发布）

- 一屏记账：交易类型快捷切换，金额、账户、日期、支出分类集中；表单固定保存区，可选资料折叠。
- 支出用途与固定 / 日常可变 / 偶发性质；月度金额汇总与固定支出筛选。
- 常用支出模板，支持每月 / 每年标记；需要手工保存实际流水，不自动记账或扣款。
- 普通流水详情与编辑，资产字段按类型显示；首页常用操作和待办前置，分布与管理按需展开。
- 定投主动选择实际状态与资金来源、核对成交日期；失败或跳过进入可修改历史，消费汇总排除定投资金转出。
- 保留旧版备份兼容、完全本地保存与无 INTERNET 权限。

安装要求：Android 8.0+。沿用原开发签名，仅供试用。APK、校验文件在 dist 中，不提交源码历史。

验证：21 项财务测试通过；360×800、390×844 浏览器检查与实际操作记录见 docs/verification.md。APK v2/v3 签名与包内资源验证通过。

限制：尚未连接安卓真机或模拟器验证安装、键盘、系统文件选择器和厂商 WebView；常用模板没有自动到期提醒；未实现自定义分类、预算额度或自动重复付款。
