# 松鼠症 SquirrelFin v0.1.17 · 历史备注检索（开发签名试用）

记一笔与编辑流水时，备注支持检索本地历史内容：聚焦查看最近使用项，输入关键词筛选，点选快速填入。候选去重并按日期倒序展示，每次最多20条；关键词检索覆盖全部历史，英文忽略大小写。

选择历史内容只修改备注，金额、用途、性质、日期及资金账户仍由用户核对。支持键盘选择、收起候选和无匹配提示，候选列表独立滚动，保存按钮固定可达。

- 安装要求：Android 8.0及以上，版本码18。
- 签名：沿用现有开发签名，仅供试用；覆盖安装仍需系统确认。
- 数据：APK默认空账本，历史备注检索在本地完成，未增加运行依赖。
- 验证：53项财务测试通过；浏览器检查手机与桌面布局、关键词筛选、点选及键盘回填和保存按钮可达。APK签名及包内资源另见验证记录。
- 已知限制：安卓真机输入法、触摸滚动及覆盖安装尚未验证；浏览器模拟视口不替代设备验证。

本版本仅本地打包，未创建GitHub Release。产物为 `SquirrelFin-0.1.17.apk` 和 `SquirrelFin-0.1.17.apk.sha256`。
