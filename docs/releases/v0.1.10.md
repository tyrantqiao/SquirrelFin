# 松鼠症 SquirrelFin v0.1.10 · 手机安全区与交互优化（开发签名试用）

修复手机页面与灵动岛、挖孔或状态栏重叠的问题。首页、全屏录入、底部导航和提示统一适配安全区；安卓通过容器调整 WebView 实际可用范围，避开状态栏、显示挖孔、系统导航与软键盘。横屏保留左右安全距离。
