# 松鼠症 SquirrelFin v0.1.12 · 首页今日收支与更新检测简化（开发签名试用）

总览首页新增「今日收支」卡片，在资产列表前展示当天已记录支出、收入和结余；点击「查看明细」可追溯当天流水。新记一笔后即时刷新，防窥隐藏汇总及明细金额；空账本明确提示尚无收支记录。统计排除转账、投资资金及关联转出，与收支分析页保持同一口径。

应用更新直接使用 GitHub Release 网页检测最新正式版本，移除先请求 GitHub API、失败后再切换的步骤。检测仍读取本仓库最新正式版本、对应的唯一 APK 附件及同名 .apk.sha256 校验文件；下载大小、SHA-256、包名、版本与签名校验，以及暂停和续传保持不变。

安装要求：Android 8.0+，版本码 13。沿用原开发签名，仅供试用，建议覆盖安装前导出备份。APK 默认空账本；更新检测与下载使用网络，不上传账本。JSON 备份为明文。

验证：45 项财务及报表测试通过，Java 更新版本边界和 Release 附件/校验文件解析测试通过。浏览器 360×640 / 390×844 检查首页空态、记账后即时更新、明细与防窥。电脑端验证当前正式 Release 网页跳转、APK 链接、同名校验文件及 HEAD 文件大小。APK v2/v3 签名通过，证书与 v0.1.11 一致，全部六项包内 assets 与源码一致。

已知限制：检测需要 GitHub 网页及附件可达，网页结构变更可能导致检测失败。安卓真机、实际更新下载续传、系统安装权限及覆盖安装尚未验证。
