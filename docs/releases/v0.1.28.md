# v0.1.28 · 生命能量时长单位（本地开发版，未发布）

保留小时和分钟明细，在生命能量结果中增加天、周、年的等值换算。

- 收支汇总、资产汇总和资产详情同时列出天、周、年。流水、分类、资产台账和记账预览补充合适的单位：达到一年用年，达到一周用周，其余小时数用天。
- 统一按 24 小时/天、7 天/周、365 天/年计算，明确是时长单位，不是工作日、寿命或退休时间。例：8760 小时约为 365 天、52.14 周、1 年。
- 换算保留最多两位小数，较小的非零等值显示“不足 0.01”，不显示为零。小于一小时保留分钟，零值和不可计算状态不添加冗余单位。
- 金额防窥同步隐藏单位换算。财务金额、精确分钟合计、真实时薪和备份格式均保持原规则。
