# v0.1.2 开发版（本地构建，尚未发布）

- 日常记账改为大号金额、自带数字键盘、用途图标和性质标签；账户、日期、备注按需展开，保存后可再记一笔。
- 支持粘贴文字或读取 UTF-8 TXT/Markdown 账单，识别日期、收支表情、原分类、备注、金额。
- 导入先预览，可逐笔改账户和分类；保留原分类，错误行阻止整批保存，重复候选默认跳过，确认后只追加勾选记录。
- 收支月份切换，导入成功后显示对应历史月份。
- 保持完全本地、整数分金额、旧备份兼容和现金流核验规则。

安装：Android 8.0+，沿用原开发签名，仅供试用。APK 与 SHA-256 文件位于 dist，不提交源码历史。

验证：27 项财务测试通过；360×800、390×844 浏览器走查与文字/文件导入实际操作见 docs/verification.md。APK 签名与包内资源校验通过。

限制：未完成安卓真机安装、实际软键盘与系统文件选择器验证；当前仅支持所述文字格式，不支持 CSV/Excel/图片识别；不能自动确认到账、定投或实物出售。
