# v0.1.32 · 生命能量与窄屏排版

填写真实时薪后，收支分析和资产中可以直接查看金额对应的投入时间。本版整合生命能量展示、时间单位、窄屏金额排版及信息层级优化。

## 更新内容

- 收支分析展示已记支出折合投入时间、分类、已覆盖笔数和待换算金额。历史支出按交易日匹配生效档案，跨档案先精确加总再取整；同参考月已经扣除的工作成本不重复换算。
- 生命能量卡片突出结果，覆盖条及参与/尚未换算金额分开呈现。历史时薪缺口、劳动净收入不为正、超出显示范围和空区间分别给出原因及处理入口，参考日期、时薪和分类收进详情。
- 资产展示金融净资产、含实物净资产及单项余额/欠款的时间等价值，已扣除负债；不代表实际累计工时、投资收益或可生活时长。
- 优先显示达到1的最大年、周、天单位，保留精确小时明细。按24小时/天、7天/周、365天/年换算，非工作日或寿命。
- 首页三张收支卡片始终同排，金额始终单行。统一适配字号、必要时移除千位逗号，但保留全部数字和两位小数；极大金额提供局部滑动和完整详情，不强制拆行。
- 记账页三张收支概览同排；新增展示跟随防窥和换算开关。账务金额、余额、投资收益和备份格式保持既有规则。
