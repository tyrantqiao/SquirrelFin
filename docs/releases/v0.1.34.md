# v0.1.34 · 全部净资产续航（开发签名试用）

- 资产续航主结果使用现金 + 投资 + 实物残值 − 负债，不再只计算现金。实物购入成本不重复计入，无现金账户也能估算。
- 直接展示可支撑天数、等值月数、平均每天消费与估算每月消费。月份统一按 30 天换算；支持本月截至今日、上个完整月、近 3 个完整月。
- 现金和金融净资产对照保留在展开项中。无正值支出不估算，负净资产显示零支撑；防窥同时隐藏金额和续航。

假设不再有收入、开支速度不变，投资及实物按登记估值变现并清偿负债，不计未来收益。记录不完整可能高估续航。

本地 APK 为开发签名试用包，要求 Android 8.0 及以上。84 项规则测试通过；浏览器 320/360/390/1280px 回归通过，已复查 390px 截图。APK v2/v3 签名验证通过，包内五项主要页面资源与源码逐字节一致。尚未进行安卓真机运行或覆盖安装验证。
