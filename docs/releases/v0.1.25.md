# v0.1.25 · 收支走势与参考时薪优化

收入、消费支出改为独立走势图，各自从零缩放；支出按正金额显示。收支差距大时两条走势都能看清，并提示两图独立刻度，不能用曲线高度比较金额。结余仍保留在汇总和明细表中。

新建参考时薪默认从记账汇总已标记工资和工作成本，展示已汇总金额；额外补录默认为 0，不重复计算。无工资记录时不预设收入，提示暂不可换算。

时间草稿默认 22 天、每天工作 8 小时、通勤 1 小时、恢复 0 小时，明确提示按实际修改；只有点击保存后生效，编辑已有档案保留原值。移除突出的小时快捷按钮，统一使用带中文单位的输入与半小时加减控件。

Android 8.0 及以上，版本码 26，既有开发签名仅供试用。备份格式及账务计算规则不变。JSON 备份为明文，恢复会替换当前数据。

- 65 项财务规则测试、app.js 语法检查通过。
- 收支走势浏览器核验覆盖 100000:1 双向差距、仅收入/仅支出、1 分钱、空账本和防窥；周/月/年逐点金额正确。
- 隔离浏览器核对默认值、空账本、取消不保存、汇总及无重复计入、半小时加减、保存与重新编辑；320/360/390/1280px 无横向溢出，390px 截图复查，460px 缩短视口提交可达。
- APK v2/v3 签名通过，全部 6 项 assets 与源码逐字节一致，沿用原签名密钥。
- 安卓真机、实际软键盘、触摸及覆盖安装未验证。
