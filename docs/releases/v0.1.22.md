# v0.1.22 · 单页时薪与记账联动（本地开发版，未发布）

真实时薪设置合并为一页，减少重复录入。入口仍为「记账 → 时间视角」。

- 时间可按每天估算：填写实际工作天数，点选常用小时数，或用半小时加减按钮微调；也可切换为整月填写。输入以分钟精度保存，每日模式记录天数与每日时长，重新打开仍保持该方式。没有默认确认工作天数或时间。
- 工资和工作成本分别选择「从记账汇总」或「手工总额」。关联模式显示参考月已标记金额，金额框只填写未记部分；切换来源分别保留草稿，避免把手工总额重复追加。新建档案默认提供关联模式，旧档案保持原手工口径。
- 记收入时可明确选择「工资 / 劳动收入」；记支出时可选「上班通勤」「工作餐」「其他工作成本」。普通餐饮、交通、报销收入和其他收入不自动纳入。
- 工作成本需填写个人承担的工作额外且未报销金额，或主动点「整笔自付」。支持部分金额，范围为 0 至本笔总金额；报销后需编辑原记录的个人承担金额，报销到账本身不自动匹配。
- 关联档案按流水日期所在参考月汇总。新增、修改、移出月份、取消标记或删除流水均会重新计算依赖该月的档案，包括覆盖的历史支出；界面持续说明为估算，不代表记账完整。
- 同参考月已扣除的成本不重复换算为消费时间；部分成本只换算其余金额。采用其他参考月或手工总额时无法逐笔判定，不擅自扣除。尚不提供消费时间合计。
- 记账预览会临时纳入正在编辑的标记与金额，不修改已存储数据；保存后与正式计算一致。流水列表明确显示工资和工作标记，收入结构中单列明确标记的工资。

## 数据与兼容

账务金额、余额和收益规则不变。流水增加可选 `workTag` 和成本记录的整数分 `workCost`；投入时间为整数分钟。新增字段均在恢复和保存时验证，包括交易类型、金额范围和关联月总额上限。

新档案使用 `lifeEnergy.schema: 2`，支持来源及每日输入信息；仍可读取 0.1.21 的 schema 1 手工档案且不自动改为关联汇总。保存新设置时升级扩展格式，旧档案的原始口径保留。旧应用无法识别 schema 2，会拒绝恢复而不是误用补充金额计算时薪；含新档案的备份请使用 0.1.22 或后续兼容版本恢复。明文 JSON 备份、替换确认和金额防窥继续保留。
