# 松鼠症 SquirrelFin v0.1.16 · 收支排版与饼图（开发签名试用）

收支页将收入、消费支出和收支结余改为金额卡片，展示上期同期对照；手机采用两列收支、独立结余布局。流水按日期分组，整行点击查看详情，保留分类、性质、账户和资金往来标识。

收支结构新增支出去向、支出性质两张饼图，图例展示金额和占比，点击分类查看对应流水。条形对比与精确同期表按需展开；旧记录未分类金额单列，空数据不生成虚假构成，防窥时隐藏图形和占比。转账及关联投资资金仍不重复计入消费支出，收支结余不代表账户余额。

资产登记采用标签选择、可选备注及本地支付宝/微信图标；零钱通和余额宝归入投资标签。备注可在详情查看和资料编辑中修改，备份兼容旧记录并校验新增备注字段；不自动迁移已有资产类别。

安装要求：Android 8.0及以上，版本码17，沿用原开发签名，仅供试用。APK默认空账本；建议覆盖安装前导出备份，备份为明文JSON。账本完全本地，现有更新检测与下载使用网络，不上传账本。

验证：53项财务规则及备份校验测试通过，JS语法和git diff --check通过。浏览器隔离账本检查320/360/390/1280px布局、四个分析视角、长备注、大额负结余、筛选、详情、记一笔、防窥，以及饼图空态、单类别整圆、多类别占比、未分类记录和分类流水查看。资产登记及备注保存、编辑、转义和模拟键盘视口检查通过。APK v2/v3签名、原签名一致性及包内资源与源码一致性已核验。
