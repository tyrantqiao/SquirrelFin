# 松鼠症 SquirrelFin v0.1.0

首个本地财富记录试用版本，采用简约卡片界面。无需登录，无服务器，不申请网络权限。

## 功能

- 金融净资产、含实物估值净资产、负债与财富分布。
- 现金、投资、贵重物品登记，存放位置与风险标签编辑。
- 收入、支出、转账、投资追加和取出。
- 估值历史、收益金额、持有期收益率及 XIRR 年化收益率。
- 日、周、月定投计划，手工核验、实际投入与完成率；支持从已登记现金账户记录资金转出。
- 实物成本、净残值与出售到账，避免重复统计。
- 基于本地数据的财富提醒、金额隐藏、JSON 备份导出与恢复。

## 安装

下载 `SquirrelFin-0.1.0-debug.apk`，传到安卓手机安装。支持 Android 8.0 及以上，建议保持 Android System WebView 更新。附件中的 `SHA256SUMS.txt` 可用于核对下载文件。

这是开发签名的试用包。升级必须使用相同签名；卸载会删除本地数据，请先导出备份。备份为明文 JSON，请妥善保管。

## 验证与限制

- 18 项自动化测试通过。
- 浏览器实际验证资产录入、100 元到 102 元的 2% 持有期收益、定投核验与资金守恒、实物出售、重载保存、备份导出恢复及手机尺寸布局。
- APK v2/v3 签名校验通过。
- 尚未连接安卓真机或模拟器，设备安装、WebView 运行及系统文件选择器仍需真机验证。
- 不连接银行、交易平台或行情服务，不自动扣款。风险标签和实物残值由用户记录。
- 首版不支持定投暂停、出售撤销、应用锁或额外数据库加密。年化收益仅为历史现金流折算。
