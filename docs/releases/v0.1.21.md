# v0.1.21 · 时间视角（本地开发版，未发布）

记一笔金额时，可自愿开启「时间视角」，查看支出折合的投入时间。

- 入口：记账 → 时间视角 → 设置参考时薪。两步填写参考月份、税后劳动收入、未报销工作附加成本，以及工作、通勤、额外恢复时间。无相关成本或时间时明确填写 0，不自动推断。
- 支出金额下方即时显示折合时间；流水详情显示参考月份及生效日。收入、转账、投资追加/取出和关联资金转出不换算。
- 更新时薪可新增生效档案；旧流水按交易日期匹配档案。历史调整会重新换算覆盖区间，保存前展示说明。可随时关闭换算，保留档案。
- 金额隐藏同步隐藏时薪和折合时间。净收入不为正时保留档案并提示不可换算；生效日前没有档案的流水不借用当前时薪。
- 仅增加本地参考数据，不生成账务流水、不修改余额及收益。首期不做月度消费时间合计，避免工作成本重复计算。

## 数据兼容

保留账本版本 `version: 1`，新增可选扩展 `lifeEnergy: {schema: 1, enabled, profiles}`，新版本逐项验证扩展。旧备份缺少该字段时默认关闭功能，无需迁移账务数据。档案收入/成本以整数分存储，时间为整数分钟；换算中间乘积使用 BigInt，避免大金额溢出，JSON 不保存 BigInt。

扩展随明文 JSON 完整备份导出和恢复；恢复仍明确提示替换。旧应用不具备扩展校验及操作能力，含此扩展的备份建议仅在 0.1.21 及以后兼容版本中恢复。金额隐藏仅遮挡展示，主动打开编辑表单仍可查看和修改原始输入，不能代替应用锁。
