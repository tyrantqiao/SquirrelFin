# 松鼠症 SquirrelFin v0.1.15 · 弧形月份与资产图表（本地构建，开发签名试用）

首页采用轻量手账布局，金额放大居中、趋势为累计概略图。左上角半圆月份转盘支持箭头、弧面滑动、滚轮和键盘切换，也可打开年/月选择器；点击收入、支出和结余可查看对应月份流水。大额金额整组纵向显示，防窥同步隐藏金额和图表。

资产页新增分布饼图、近6/12个月金融净资产与含实物净资产折线、单项资产占比条及逐月金额表。图例可筛选台账，保留资产结构、余额变化和收益核验报表。历史缺口显示 — 并断开曲线，不补零，不推断历史市价；负债从净资产扣除，余额变化不作为收益。4%提取模块已移除。

记账页归并收支对照、分类/节奏/账户分析和流水表，记一笔改为右下角悬浮按钮，手机导航上方留出位置。统计和明细仍排除关联投资转出重复计入消费支出。电脑预览服务修复SVG类型识别，仍仅监听127.0.0.1。

安装要求：Android 8.0+，版本码16，沿用原开发签名，仅供试用。APK默认空账本，电脑预览示例数据不进入安装包。建议覆盖安装前导出备份；JSON备份为明文。账本完全本地，更新检测和下载使用网络，不上传账本。

验证：52项财务/报表测试、Java版本边界与Release附件/校验文件解析测试、JS语法和git diff --check通过。浏览器360/390/1280px检查图表、历史缺口、空态/负值、防窥、筛选、详情、月份控制、记账视角和悬浮按钮。APK v2/v3签名通过，证书与已发布v0.1.14一致，全部六项包内assets与源码SHA-256匹配。
