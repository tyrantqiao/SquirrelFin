# v0.1.33 · 按支出速度衡量资产续航（开发签名试用）

- 收支分析以支出时薪为主：所选周、月、年区间的已记消费 ÷ 自然小时。工作通勤等已记消费保留，转账、投资追加/取出和关联转出不计消费；无记录的日子仍计入时间分母。
- 分别展示工资时薪（税后劳动收入 ÷ 工作小时）、真实时薪（扣工作成本、计通勤与恢复），以及一份参考月工资和每工作 1 小时能覆盖的生活开支时长。工资档案沿用已有手填或记账关联，不增加重复填报。
- 资产页默认估算现有现金能支撑多久，可选择本月截至今日、上个完整月或近 3 个完整月；展开查看扣负债后的金融净资产、含实物估值净资产全部变现情景。资产列表及详情同步采用支出基准。
- 没有工资档案也能估算续航。无正值支出时暂不估算，不显示无限续航；负净资产为零支撑并提示净负债，欠款的金额等效时长另作说明。大金额和时长溢出有明确提示；防窥隐藏金额及换算结果。

## 口径与限制

支出时薪 = 已记消费 ÷（包含首尾日期的自然日数 × 24）。本月截至今日按整日统计，近 3 个月以总消费除总自然小时，不对各月时薪作简单平均。

资产续航假设不再有收入、支出速度保持不变，不计未来收益。默认现金情景未一次性扣清全部负债，投资和实物场景需按登记估值变现、清偿负债。实际流动性和变现金额可能不同；工作成本仍按历史基准保留，不预测停止工作后的开支变化。记录不完整可能高估续航。

工资覆盖开支按扣工作成本前的税后劳动收入计算，避免与已记消费中的工作成本重复扣除。工资参考月和支出基准独立展示，参考月整份收入不表示所选区间实际已到账工资；单笔消费原有真实时薪换算明确为劳动投入。

不新增持久化字段，原有工资档案及流水保持备份兼容；恢复含关联字段的备份仍需使用支持 schema 2 的版本。
