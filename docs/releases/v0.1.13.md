# 松鼠症 SquirrelFin v0.1.13 · 总览信息整合（开发签名试用）

总览将净资产、财富分布和今日收支整合为同一张卡片，按组展示金额与占比。手机纵向排版，桌面将财富分布与今日收支并排展示；统计口径与财富提醒在卡片底部按需展开。

移除总览「我的资产」模块，资产查看与登记统一从资产页进入。「记一笔」放在总览卡片右上角，今日收支保留明细入口；防窥同时隐藏金额、占比及分布条。财务计算与数据格式保持兼容，收支结余不作为投资收益或净资产变化。

安装要求：Android 8.0+，版本码 14。沿用原开发签名，仅供试用，建议覆盖安装前导出备份。APK 默认空账本；账本保存在本地，更新检测与下载使用网络，不上传账本。JSON 备份为明文。

验证：45 项财务及报表测试通过；浏览器检查 360×640、390×844 和桌面分组布局，无横向溢出，记账入口、防窥、统计说明与资产页入口正常。APK v2/v3 签名通过，全部六项包内 assets 与发布源码一致，证书与既有开发签名一致。

已知限制：安卓真机、软键盘、实际更新下载续传、系统安装权限与覆盖安装尚未验证。更新检测依赖 GitHub 网页与附件可达，网页结构变更可能导致检测失败。
