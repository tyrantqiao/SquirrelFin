# v0.1.27 · 收支与资产的生命能量（本地开发版，未发布）

填写并开启真实时薪后，在收支分析和资产中直接查看生命能量换算。保留待发布的收支概览三卡同排布局。

- 收支分析：展示已记支出折合投入时间、按交易日匹配档案的覆盖笔数和未换算金额。分类明细按需展开，并展示已排除的同参考月工作成本及参考依据。支出流水列表同步显示换算。
- 跨档案汇总按各笔交易日期选择生效时薪，同档案先汇总金额，再用整数分及 BigInt 有理数加总精确分钟，最后统一取整。不会用当前时薪除全年支出，也不会先把每笔取整再相加。
- 已经在对应时薪扣除的同参考月个人承担工作成本，不重复换算；混合消费只换算其余部分。手工或补录成本无法逐笔排除时，明确提示合计可能仍含工作成本、仅供参考。参考月外工作成本没有从该档案逐笔扣除，仍按支出换算，不展示实际劳动时间占比。
- 转账、投资追加/取出和关联资金转出不算消费；不可换算记录计入未覆盖金额，不当成零。暂无支出、缺少档案、净收入不为正和超出显示范围分别处理。
- 资产页展示金融净资产、含实物净资产按当前生效参考时薪折合的投入时间。两项均扣负债，后者另含实物残值；负数显示为净负债对应投入。资产台账及详情也显示单项金额或欠款的时间等价值。
- 金额换算不代表实际累计工时、投资收益或可生活时长，不影响账务、估值或收益率。隐藏金额时同时隐藏折合时间与参考金额，关闭换算后移除新增展示。
