# v0.1.23 · 真实时薪与记账联动

新增「真实时薪」：把税后工资扣除工作额外成本，再除以工作、通勤和额外恢复时间，帮助理解一笔支出对应的劳动投入。入口为「记账 → 真实时薪」。

## 本次功能

- 单页设置参考月份、收入、工作成本及投入时间；支持每天估算或整月填写、快捷时长、半小时加减和实时预览。
- 记收入时可选择「工资 / 劳动收入」；记支出时可选择「上班通勤」「工作餐」「其他工作成本」。参考月已标记流水可动态汇总，并补充未记部分，减少重复填写；也可保留手工总额。
- 工作成本支持部分个人承担金额，仅扣除额外且未报销部分，或主动确认整笔自付。普通交通、餐饮及报销款不自动纳入。
- 修改、删除或取消标记后同步重算关联档案；支出录入及详情显示折合时间，按交易日期匹配生效档案，已扣除的同参考月成本不重复换算。
- 支持关闭换算、金额防窥和本地完整备份。保留旧手工档案口径，不自动改成关联模式；账务金额、余额及投资收益计算规则不变。

## 安装与备份

Android 8.0 及以上，版本码 24。APK 使用既有开发签名，仅供试用；签名证书与 v0.1.20 一致，以保留覆盖安装兼容性。覆盖安装前建议导出备份；卸载或清除应用数据会丢失本地账本。默认空账本，无登录，账本数据保存在本地；网络仅用于已有应用更新功能。

备份为明文 JSON。新时薪档案使用 lifeEnergy.schema 2，兼容读取 schema 1 手工档案；含新档案的备份须用 v0.1.22 及后续兼容版本恢复，旧应用会拒绝该扩展格式。恢复操作替换当前数据，保存和恢复均校验新增标记、成本金额及档案字段。
