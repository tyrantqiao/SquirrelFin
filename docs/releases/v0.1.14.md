# 松鼠症 SquirrelFin v0.1.14 · 月度收支与近周明细（开发签名试用）

首页改为月度收支表格，显示所选月份的收入、消费支出和结余。增加年月筛选，默认当前月份；当前月统计截至今天，历史月统计完整月份。移除首页资产概览和调整入口，资产管理从资产页进入，保留「记一笔」。

新增近七天报表明细，展示已保存的盘点、估值、收支与转账/投资流水。支持全部、资产变更、收入和支出筛选，每页五条，可打开原资产或流水详情。近七天明细按今天及前六天显示，不随上方月筛选改变；完整报表沿用所选月份。

消费支出排除转账与关联投资转出。估值显示记录金额，不作为投资收益；同日估值修改会替换原记录，明细不保留操作审计日志。收支结余不等于投资收益或净资产变化。

安装要求：Android 8.0+，版本码 15。沿用原开发签名，仅供试用，建议覆盖安装前导出备份。APK 默认空账本；账本完全本地，更新检测与下载使用网络，不上传账本。JSON 备份为明文。
