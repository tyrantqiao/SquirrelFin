# 松鼠症 SquirrelFin v0.1.11 · 收支多视角分析与记账简化（开发签名试用）

收支页增加「概览、收支结构、消费节奏、账户分布」四个分析视角，支持按周、月、年和历史日期查看记录。展示收入、消费支出、结余、上期同期变化与日/月趋势；补充收入来源、用途排行、支出性质、分类增减、星期日均、工作日与周末对比、支出中位数、最高支出日和大额支出占比。分类与账户可追溯本期及上期同期流水，防窥开关同时隐藏金额、比例与图表。

首页「记一笔」直接进入收支表单，用途、日期和备注同页填写，金额使用系统小数键盘，保存区固定在底部。日常收支无需登记账户；支出性质、账户关联和常用模板按需展开。转账及投资资金仍要求必要账户，缺少时明确提示。

统计仅包含已记录收入和非关联消费支出，排除转账、投资追加/取出及关联资金转出。结余不是投资收益或净资产变化；未记支出不代表实际零消费。同期按已过天数对齐，短上期按实际天数封顶。工作日指周一至周五，不调整法定节假日。账本格式保持兼容。

安装要求：Android 8.0+，版本码 12。沿用原开发签名，仅供试用；建议覆盖安装前导出备份。APK 默认空账本。账本保存在本地，无登录、服务器或广告；更新检测与下载使用网络，不上传账本。JSON 备份为明文。

验证：43 项财务及报表测试通过，Java 更新版本边界及附件解析测试通过，JS 语法与 Git 差异检查通过。浏览器检查空账本和隔离示例账本、390×844 与 360×640 手机布局、分类/账户流水追溯、防窥及记账保存入口。APK v2/v3 签名、版本、历史签名证书及全部包内 assets 一致性已核验。
