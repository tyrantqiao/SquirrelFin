# 支出记录方式与本次设计

检索日期：2026-10-10。以下是产品设计参考，不是个性化理财建议。

## 常见方式

1. 按用途逐笔记账：记录金额、日期、账户和用途，月末按餐饮、住房、交通等汇总。最适合快速记录实际发生的支出。[CFPB 支出追踪与预算介绍](https://www.consumerfinance.gov/archive/blog/budgeting-how-to-create-a-budget-and-stick-with-it/)
2. 固定与可变支出：固定费用便于预估；可变费用要按实际金额记录。同样定期发生的水电账单也可能金额可变，重复周期不能直接等同于金额固定。[CFPB 财务术语](https://www.consumerfinance.gov/consumer-tools/educator-tools/youth-financial-education/glossary/)
3. 重复交易：为常见账单保存资料与周期，减少重复输入；实际付款仍需核对。[YNAB 重复交易说明](https://support.ynab.com/scheduled-transactions-a-guide-BygrAIFA9?mobile-help=true)
4. 信封法 / 零基预算：先给已有的钱分配用途，再对照预算花费，适合主动预算管理，但增加初次配置和日常维护。[YNAB 零基预算介绍](https://www.ynab.com/blog/what-is-a-zero-based-budget)
5. 50/30/20：按需要、想要、储蓄等比例安排收入，属于预算方法；比例需适应个人情况，不宜成为记账时强制填写的字段。[CFPB 支出规则练习](https://files.consumerfinance.gov/f/documents/201606_cfpb_rules-to-live-by_my-spending-rule-to-live-by.pdf)

## 本次取舍（0.1.1）

以逐笔记录为主，采用「用途 + 性质」两个独立字段，保留一屏默认操作。暂不加入预算配置流程。

- 用途：餐饮、居住、交通、购物、水电通讯、医疗、教育、娱乐、人情、保险、其他。
- 性质：固定支出（定期且金额稳定，如房租、订阅）；日常可变（餐饮、水电）；偶发支出（临时维修、旅行等）。由用户选择，不从类别推定。
- 重复频率独立保存在常用模板里：不固定、每月、每年。因此金额可变的水电也能存为每月模板。
- 模板是快速填单资料，不能代表实际支付；点击后检查日期与金额，再保存。没有自动生成流水、到期提醒或后台任务。
- 支出分类不用于投资追加、取出或内部转账。定投关联的现金转出从消费支出统计中排除。
- 月度汇总以流水日期所属自然月计算；旧流水不猜分类，显示未分类，可编辑补充。分类不会改变整数分金额、账户余额与收益规则。
- 备份保持 version 1，新字段为可选扩展；旧备份可恢复，新分类与模板会随完整备份导出并校验。

后续如增加账单提醒，应将计划和实际付款分开，不因到期直接扣余额。
